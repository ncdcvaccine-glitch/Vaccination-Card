# سجل التطبيقات الوطني — تطبيق ويب (PWA)

المركز الوطني لمكافحة الأمراض — ليبيا
**إعداد: د. محمد الجرنازي**

تطبيق يُثبَّت على الهاتف (Android / iPhone) ويعمل بدون إنترنت بعد أول فتح.

## محتويات المجلد
- `index.html` — التطبيق نفسه
- `manifest.webmanifest` — بيانات التطبيق (الاسم، الألوان، الأيقونات)
- `sw.js` — العمل بدون إنترنت
- `icons/` — شعار المركز وأيقونات التطبيق
- `.nojekyll` — يمنع GitHub من معالجة الملفات

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على github.com (مثلاً `vaccination-app`) واجعله **Public**.
2. اضغط **Add file ← Upload files** وارفع **كل محتويات المجلد** (بما فيها مجلد `icons` والملف `.nojekyll`) ثم **Commit changes**.
3. من **Settings ← Pages**: اختر Source = **Deploy from a branch**، والفرع **main**، والمجلد **/ (root)** ثم **Save**.
4. بعد دقيقة تقريباً يظهر الرابط:
   `https://USERNAME.github.io/vaccination-app/`

## التثبيت على الهاتف
- **Android (Chrome):** افتح الرابط واضغط زر **«تثبيت التطبيق»** في أعلى الصفحة.
- **iPhone (Safari):** اضغط زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

## تحديث التطبيق لاحقاً
بعد تعديل `index.html` غيّر رقم النسخة في أول سطر من `sw.js` (مثلاً `vax-app-v2`) حتى تصل التحديثات للمستخدمين.
